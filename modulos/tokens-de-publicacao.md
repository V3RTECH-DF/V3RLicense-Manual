# Tokens de publicação

Veja o passo a passo em **[Gerenciar tokens de publicação](/processos/gerenciar-tokens-publicacao/)**.

{: .captura-pendente }
> **Print pendente:** tela de Tokens de publicação com a lista e o modal de token recém-gerado. Viewport: desktop e mobile.

## Colunas da listagem

Rótulo · Status (Ativo/Revogado) · Criado em · Último uso.

## Campo do formulário

Rótulo (para identificar o uso — não limita o escopo do token).

## Ações

Revogar token (só em tokens ativos; a linha não é excluída).

{: .warning }
> Sem escopo por produto hoje — qualquer token publica release de qualquer produto. Detalhe completo em **[Gerenciar tokens de publicação](/processos/gerenciar-tokens-publicacao/)**.
